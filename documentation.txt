=== Полная документация к программе DataStructures ===

1. НАЗНАЧЕНИЕ ПРОГРАММЫ
Программа предоставляет два основных функционала:
- Операции с матрицами:
  * Стандартное умножение матриц
  * Умножение с транспонированием
- Конвертация чисел:
  * Перевод float/double в HEX-формат IEEE 754
  * Обратное преобразование из HEX в десятичное число

4. ОПИСАНИЕ АЛГОРИТМОВ И ФУНКЦИЙ

4.1. Матричные операции:
- Multiply(): Стандартное умножение матриц
- Transpose(): Транспонирование матрицы
- MultiplyTransport(): Умножение с транспонированием

4.2. Конвертация чисел:
- ConvertBunary(): Преобразование в двоичный формат
- ConvertHex(): Преобразование в HEX IEEE 754
- ConvertDec(): Обратное преобразование из HEX

5. ВХОДНЫЕ И ВЫХОДНЫЕ ДАННЫЕ

5.1. Матричные операции:
Вход:
- Размер матрицы (целое число)
- Элементы (генерируются автоматически)
Выход:
- Результирующая матрица
- Время выполнения

5.2. Конвертация чисел:
Вход:
- Для ConvertHex: десятичное число (float/double)
- Для ConvertDec: HEX-строка
Выход:
- Для ConvertHex: HEX-строка
- Для ConvertDec: десятичное число

6. ТРЕБОВАНИЯ К СИСТЕМЕ

6.1. Аппаратные требования:
- Процессор с поддержкой IEEE 754
- 1 ГБ оперативной памяти
- 10 МБ дискового пространства

6.2. Программные требования:
- ОС: Windows/Linux/macOS
- Компилятор C++17 (GCC, Clang, MSVC)
- Стандартная библиотека C++

7. ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ

7.1. Матричные операции:
1. Выберите пункт 1 в главном меню
2. Введите размер матрицы
3. Выберите тип умножения (1 или 2)
4. Получите результат и время выполнения

7.2. Конвертация чисел:
1. Выберите пункт 2 в главном меню
2. Выберите направление конвертации
3. Введите число или укажите файл
4. Получите результат преобразования

8. ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ

8.1. Назначение программы:
Программа предоставляет два основных функционала:
- Операции с матрицами (умножение)
- Конвертация чисел между форматами

8.2. Основные команды:
Главное меню:
1 - Работа с матрицами
2 - Конвертация чисел
3 - Эта справка
0 - Выход

8.3. Работа с матрицами:
Доступные операции:
1 - Стандартное умножение
2 - Умножение с транспонированием

Входные данные:
- Размер матрицы (целое число)
- Элементы генерируются автоматически

8.4. Конвертация чисел:
Доступные преобразования:
1 - Десятичное > HEX (IEEE 754)
   - Выберите тип: 1-float (32 бита), 2-double (64 бита)
2 - HEX > десятичное

Форматы данных:
- float: 8 HEX-символов
- double: 16 HEX-символов
