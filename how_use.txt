Краткое руководство пользователя
1. Назначение программы
Программа выполняет умножение квадратных матриц двумя способами:

Стандартный метод: прямое умножение матриц.

Метод с транспонированием: умножение с предварительным транспонированием второй матрицы.

Программа также измеряет время выполнения операции.

2. Запуск программы
Скомпилируйте и запустите файл DataStructures.cpp.

Следуйте инструкциям на экране.

3. Инструкция по использованию
Выбор источника ввода:

Введите 1 для чтения размерности матрицы из файла.

Введите 2 для ручного ввода размерности с клавиатуры.

Ввод размерности:

Из файла:

Укажите имя файла (например, input.txt).

Файл должен содержать одно целое число — размерность матрицы (например, 3).

С клавиатуры:

Введите целое положительное число (например, 4).

Выбор метода умножения:

Введите 1 для стандартного умножения.

Введите 2 для умножения с транспонированием.

Результат:

Программа выведет время выполнения операции в секундах.

Для повторного запуска введите y, для выхода — n.
